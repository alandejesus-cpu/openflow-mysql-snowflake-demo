# OpenFlow MySQL to Snowflake Demo

Personal portfolio project demonstrating a multi-source CDC
ingestion architecture using Snowflake OpenFlow Gen2.

## Objective

Build a reproducible data ingestion pipeline that captures
changes from multiple MySQL databases and delivers the data
into Snowflake.

## Architecture

MySQL → Snowflake OpenFlow Gen2 → Snowflake

## Technologies

- MySQL
- Snowflake
- Snowflake OpenFlow Gen2
- Python
- Jinja
- SQL
- Git / GitHub

## Main Components

- OpenFlow Deployment
- OpenFlow Runtime
- OpenFlow Connectors
- MySQL CDC
- Snowflake RAW layer
- Snowflake STAGING layer
- Python configuration automation
